# object_detection_format

## Overview

Format-independent annotation model and writers serializing it into detection formats.

## Components

| Component | Description |
| --------- | ----------- |
| [annotation/](./annotation/README.md) | Validated boxes, objects, images and the dataset with its class list. |
| [writer/](./writer/README.md) | Writers for COCO, YOLO, Pascal VOC, LabelMe and Create ML, and the `AnnotationFormat` enum. |
